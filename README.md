# TCs-under-SAI
Researching the impact of Stratospheric Aerosol Injection (SAI) on Tropical Cyclones (TCs)

In this study, SAI is deployed from 2050 onwards targeting an early-century global mean surface temperature target to offset global warming. Simulations are performed with the fully-coupled CESM1(CAM) at 0.25  and 0.1 degree nominal resolution for the atmosphere and ocean components, respectively. This configuration allows for an explicit representation of TCs. 

The experiments consist of three six-member ensembles representing the early-century reference climate (perpetual year 2000 conditions), a late-century warm climate under increased CO2 forcing following the RCP8.5 scenario, and a late-century climate where SAI offsets the global mean warming due to the increased CO2 forcing under RCP8.5. 

This repository is split in two main parts:
- `tracker`
  source code for identifying TCs/TC seeds and generated track datasets for the experiments
- `analysis`
  source code, processed data and figures for analyzing the impact of SAI on tracked TCs in the experiments

Further details on the repository structure are provided in both parts separately.
